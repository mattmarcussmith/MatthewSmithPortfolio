Project Details

Workforce Operations Platform

A focused internal workforce application for HR and department managers to manage employee records, department structure, job titles, work status, leave requests, access roles, and audit history from one centralized system.

GitHub Repository Coming Soon Live Demo Coming Soon

Business Scope

  • Centralized employee record management
  • Department and job title organization
  • Work status tracking for active, onboarding, on leave, inactive, and terminated employees
  • Leave request submission, approval, rejection, and history
  • Role-based access for HR admins, managers, and viewers
  • Audit history for important workforce record changes

Technical Scope

  • Angular frontend with strongly typed models
  • ASP.NET Core Web API backend
  • Controller to Service to DbContext architecture
  • DTO-based request and response contracts
  • EF Core Code First with SQLite
  • Microsoft Entra ID authentication
  • Postman authentication validation
  • Swagger/OpenAPI endpoint testing
