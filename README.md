# Matthew Smith Portfolio

A static Angular portfolio website built to present my background as a .NET Software Engineer, highlight my technical experience, and showcase a full-stack portfolio project focused on Angular and ASP.NET Core Web API development.

## Purpose

This portfolio provides a direct professional URL for job applications and gives employers a concise view of my technical background, resume, education, certifications, and project work.

## Featured Project

### Workforce Operations Platform

Workforce Operations Platform is a portfolio project built around a realistic internal business need: helping HR and department managers centralize workforce data, track employee status, manage leave visibility, and control role-based access.

The project is designed to demonstrate practical full-stack capability through a business problem that reflects common enterprise application patterns.

Planned technical scope:

- Angular frontend
- TypeScript
- Bootstrap
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- Microsoft Entra ID authentication
- Postman authentication validation
- Swagger/OpenAPI endpoint testing
