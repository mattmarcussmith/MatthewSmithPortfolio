Featured Project

EP Employee Portal

Status: In Progress

Employee Portal is an enterprise HRIS portfolio project built around a realistic internal business need: helping HR teams and department managers securely centralize employee records, manage onboarding, track department assignments, maintain emergency contacts, assign skills, and support controlled employee offboarding.

The purpose of the project is to demonstrate practical full-stack capability by solving a business problem that reflects common enterprise application patterns employers expect: secure ASP.NET Core Web APIs, strongly typed DTOs, Entity Framework Core data access, validation, role-based authorization, audit fields, soft deletes, paged reporting views, and maintainable Angular integration.
