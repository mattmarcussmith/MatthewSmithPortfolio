Featured Project

OpsFlow

Status: In Progress

OpsFlow Platform is a mid-size enterprise system designed to orchestrate internal business operations through structured work items, approvals, tasks, and controlled workflow state transitions. It provides a unified operational layer for managing and executing organizational work.

The project demonstrates production-style .NET architecture patterns including layered API design, DTO-based contracts, EF Core persistence, workflow state machines, validation pipelines, role-based authorization, audit logging, and Blazor WebAssembly UI composition.
