Project Details

Retail Lakehouse ETL Pipeline

An end-to-end Databricks data engineering project that ingests raw retail data, transforms and validates records through Bronze and Silver layers, and produces curated Gold datasets for analytics and reporting.

GitHub Repository

02 / ETL Workflow

Pipeline Processing

The project separates each major data engineering responsibility into clear processing stages that can be executed and monitored independently.

01

Ingest

Load source files into Bronze Delta tables while preserving raw records and adding ingestion metadata.

02

Validate

Check required fields, data types, null values, duplicate records, and invalid source data.

03

Transform

Clean records, standardize values, join related datasets, and build reusable Silver tables.

04

Aggregate

Create Gold datasets containing business-level metrics and analytics-ready summaries.
