Project Details

EP Employee Portal

An enterprise HRIS application for HR teams and department managers to securely centralize employee records, manage onboarding, maintain department assignments, track emergency contacts, assign employee skills, enforce role-based access, and support controlled employee offboarding from one centralized system.

GitHub Repository Coming Soon Live Demo Coming Soon

Business Scope

  • Centralized employee profile and workforce record management
  • Structured onboarding for new employee creation
  • Department, manager, and organizational assignment tracking
  • Emergency contact management for employee safety records
  • Employee skill tracking for workforce visibility
  • Role-based access for HR administrators and employees
  • Controlled offboarding through employee deactivation
  • Audit visibility for employee record creation and updates

Technical Scope

  • Angular frontend with strongly typed DTO-aligned models
  • Angular Material forms, dialogs, and UI controls
  • AG-Grid employee directory with paging, sorting, and search
  • ASP.NET Core Web API backend
  • Controller to Service to DbContext architecture
  • DTO-based request and response contracts
  • FluentValidation business rule validation
  • EF Core Code First with SQLite migrations
  • Microsoft Entra ID authentication and role-based authorization
  • Serilog structured logging and sensitive-data logging restrictions
  • Swagger/OpenAPI endpoint testing
  • Postman authentication validation
